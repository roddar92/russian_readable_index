# Russian Readable Index

The combination of Irina V. Oborneva's formula and Profiling-UD features was used in this project. We evaluated this approach using abstracts of Russian-language articles. The results demonstrate that syntactic features provide a deeper analysis of text complexity than the Flesch Reading Ease (FRE) index, which relies solely on average sentence length and average syllable count. 

[Used dataset](https://github.com/iis-research-team/AINL-Eval-2025/tree/main).
